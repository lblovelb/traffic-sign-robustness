# Project vault

This folder is the project's memory. Open it in Obsidian ("Open folder as
vault") or read it in VS Code — it's plain Markdown.

Claude forgets everything between sessions; these notes don't. Agents read and
write here so that decisions and results survive.

- [[decisions]] — why the project is set up the way it is
- [[experiment-log]] — one entry per experiment run
- [[analysis]] — the latest interpretation of the results (written by `results-analyst`)
- [[learnings]] — what Love learned about ML and the Claude workflow
